\# Oberyn's Clears Tracker



A \[Blish HUD](https://blishhud.com/) module for Guild Wars 2 that tracks your daily and weekly PvE instance clears.



\## Features



\### Daily Tab

\- \*\*Daily Raid Bounties\*\* — Today's 4 active bounties with completion status

\- \*\*Tomorrow's Bounties\*\* — Plan ahead with tomorrow's 4 bounties



\### Weekly Raids Tab

\- Tracks all 8 raid wings and their bosses

\- Shows cleared/uncleared status per boss



\### Weekly Strikes Tab

\- Tracks all strike missions across all expansions (IBS, EoD, SotO, VoE)

\- \*\*Forging Steel manual toggle\*\* — Since Forging Steel is not tracked by the GW2 API, click its icon to manually mark it as cleared. Progress is saved locally and resets with the weekly server reset.

\- IBS Emissary Chest progress tracker (Steel/Raven/Shiverpeaks/Whisper/Cold orbs)



\## Known Issues

1\. Slothasor's Daily Raid Bounty completion is currently untracked

2\. Forging Steel requires manual tracking due to GW2 API limitations



\## Requirements

\- \[Blish HUD](https://blishhud.com/) 1.2.0 or higher

\- Guild Wars 2 API key with \*\*Account\*\* and \*\*Progression\*\* permissions



\## Installation

1\. Download the latest `.bhm` file from \[Releases](https://github.com/OberynCrowstorm/ClearsTracker/releases)

2\. Place it in your Blish HUD modules folder (`Documents\\Guild Wars 2\\addons\\blishhud\\modules\\`)

3\. Enable the module in Blish HUD settings

4\. Add your GW2 API key in Blish HUD with Account and Progression permissions
